סדנת Claude ו-Claude Code

  • 2 עד 3 שעות
  • פרונטלי או בזום
  • מתחילים עד מתקדמים

סדנת Claude Code מלמדת צוותים לעבוד עם Claude ועם Claude Code, סוכן הקוד של Anthropic. בחלק הראשון עובדים עם Projects, Skills ו-Artifacts. בחלק השני כל משתתף בונה כלי עובד, כמו דשבורד, אוטומציה או אפליקציה פנימית, בלי לכתוב קוד בעצמו. הסדנה נמשכת שעתיים עד שלוש.

שאלות נפוצות על סדנת Claude Code

צריך לדעת לתכנת?

לא. Claude Code כותב את הקוד. צריך לדעת להסביר מה רוצים, ואת זה מתרגלים בסדנה.

צריך מנוי בתשלום?

כן, ל-Claude Code נדרש מנוי Claude או מפתח API. נעזור להגדיר לפני הסדנה.

אפשר להעביר את הסדנה בזום?

כן. הסדנה מועברת פרונטלית בכל הארץ, או בזום עם אותו תוכן ואותם תרגילים.

מה עם אבטחת מידע בסדנה?

עובדים בחשבונות הארגוניים ועם נתונים בדויים, כך ששום מידע רגיש לא נכנס לכלים. כל משתתף מקבל כללי שימוש בטוח.
