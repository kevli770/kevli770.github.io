## ההסכמה הרשמית של Anthropic

Anthropic שחררו הסכמה רשמית ששווה הרבה כסף, ואיתה 9 קורסים בחינם. ההסכמה מוכיחה ידע מעשי לעבודה עם Claude, מהבסיס ועד בניה של סוכני AI ואינטגרציה עם AWS ו-Google Cloud.

לינק לכל הקורסים: [anthropic.com/learn](https://www.anthropic.com/learn)

## 1. Claude 101

**מה לומדים:** הבסיס. מה Claude יודע לעשות ומה רוב האנשים עושים לא נכון.

- יכולות מרכזיות של המודלים
- טעויות שיגרמו לאי-הבנה
- Best practices לשימוש יומיומי
- חובה: קורס פתיחה לכל משתמש חדש

## 2. AI Fluency

**מה לומדים:** איך לחשוב נכון כשעובדים עם AI. מתי לתת לו לרוץ, מתי לבדוק.

- מודלים לעבודה משותפת עם AI
- מתי לסמוך על התוצאות ומתי לבדוק פעמיים
- זיהוי מגבלות AI ושגיאות

## 3. Building with the Claude API

**מה לומדים:** הליבה של ההסכמה, 8 שעות. איך לבנות אפליקציות אמיתיות עם Claude.

- חיבור Claude לכלים
- קריאת קבצים ועיבוד מסמכים
- בניית צ'אטבוטים חכמים
- Streaming, tool use, prompt caching
- הליבה של ההסכמה: קורס קריטי

## 4. Agent Skills

**מה לומדים:** איך לבנות ל-Claude יכולות חדשות ו-skills.

- הגדרת מבנה של skill
- SKILL.md ו-frontmatter
- אינטגרציה עם Claude Code ו-Claude Desktop
- דוגמאות מעשיות

## 5. Claude Code in Action

**מה לומדים:** הכלי שנותן ל-Claude לכתוב ולתקן קוד ישירות על המחשב שלכם.

- התקנה והגדרה ראשונית
- תהליך עבודה עם Claude Code
- Tool use וPipeline בואים
- אינטגרציה עם git, ריצת פקודות, קריאת קבצים

## 6. MCP

**מה לומדים:** Model Context Protocol, הדרך לחבר את Claude לעולם החיצוני, קבצים, אתרים, כלים.

- מה זה MCP ולמה הוא נוצר
- התקנת MCP servers
- חיבור לבסיסי נתונים, APIs חיצוניים, filesystem
- שימוש ב-Claude Desktop וב-Claude Code

## 7. MCP Advanced

**מה לומדים:** אותו הדבר ברמה מתקדמת, לסביבות עבודה אמיתיות.

- בניית MCP servers מותאמים אישית
- Authentication ואבטחה
- ניהול מצבים ואירועים
- Production deployments

## 8. Claude on AWS Bedrock

**מה לומדים:** איך להריץ Claude דרך Amazon Web Services. לחברות שעובדות עם AWS.

- הגדרת Bedrock
- ויסות API
- ניהול עלויות והרשאות
- Compliance ונתונים בסביבות AWS

## 9. Claude on Google Cloud

**מה לומדים:** אותו דבר, דרך Google Cloud. לחברות בסביבת GCP.

- הגדרה ב-Vertex AI
- ויסות Claude דרך GCP APIs
- אינטגרציה עם שירותי Google
- Compliance ונתונים ב-GCP

## ההסכמה עצמה

אחרי שתסיימו את הקורסים אתם יכולים לגשת להסכמה הרשמית של Anthropic. ההסכמה מוכיחה שיש לכם ידע מעשי לבנות עם Claude, והיא מהווה נכס לקורות חיים ולתפקידים בתחום ה-AI.
