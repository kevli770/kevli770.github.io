מאת קווין ליאקס. פורסם 2026-07-04. נושא: Claude ו-Claude Code.
העמוד המלא: https://kevli770.github.io/guides/artifacts

## מה זה Artifacts ב-Claude Code

Anthropic שחררו פיצ'ר חדש ל-Claude Code בשם Artifacts, ורוב האנשים עדיין לא מכירים אותו. במקום להסתכל על שורות טקסט ופלט בטרמינל שחור, אתם מבקשים מ-Claude Code לפרסם את העבודה שלו כדף חי בדפדפן.

כל Artifact הוא דף HTML עצמאי (self-contained) שנפתח בכתובת משלו תחת claude.ai, פרטי כברירת מחדל, ואפשר לשתף אותו בקליק. במקום לנחש מה קורה מהטרמינל, אתם פשוט רואים בעיניים.

**הפיצ'ר פתוח עכשיו לכל מנויי Pro ו-Max.**

## איך מפעילים את Artifacts

הפיצ'ר מגיע יחד עם Claude Code. כדי לוודא שהוא פעיל, פותחים את מסך ההגדרות עם הפקודה:

```
/config
```

בקטגוריית INPUT & CONTROLS מוודאים שהשורה Artifacts מסומנת כ-true. זהו, אתם מוכנים לעבודה.

## מה אפשר לבקש: 4 סוגי תוצרים

הכוח האמיתי הוא לבקש מ-Claude Code להסביר את העבודה שלו ויזואלית. הנה ארבע בקשות חזקות שכדאי להכיר:

| # | סוג תוצר | מה זה נותן לכם |
|---|---|---|
| **1** | **הסבר על כל שינוי PR** | כל שינוי בקוד עם הסבר צמוד לשורה, רואים בדיוק מה השתנה ולמה, בלי לקרוא diff יבש. |
| **2** | **דיאגרמת ארכיטקטורה** | דיאגרמה שנגזרת מהקוד עצמו ומראה איך כל החלקים במערכת מתחברים. |
| **3** | **מסלול בקשה מקצה לקצה** | המסלול שבקשה עוברת במערכת: מהלקוח, דרך ה-gateway וה-router, ועד ה-database. כדי להבין מה בעצם קורה. |
| **4** | **דשבורד חי מהדאטה** | דשבורד עם גרפים מהדאטה שה-session כבר משך, במקום טבלה יבשה. מתעדכן בזמן אמת. |

## איך משתמשים: צעד אחרי צעד

### שלב 1: מבקשים בשפה חופשית

לא צריך פקודה מיוחדת. פשוט אומרים ל-Claude Code מה אתם רוצים לראות, ומוסיפים שיהפוך את זה ל-Artifact. לדוגמה:

```
Walk me through this PR as an artifact and annotate the diff
```

### שלב 2: Claude Code בונה ומבקש אישור

Claude Code כותב קובץ HTML, מסמן אותו כ-Artifact, ומבקש אישור לפני שהוא מפרסם דף לרשת. מאשרים והוא ממשיך.

### שלב 3: מקבלים לינק והדף נפתח

אתם מקבלים לינק בפורמט claude.ai/code/artifact, והדפדפן נפתח לבד עם דף אינטראקטיבי אמיתי. משם אפשר ללחוץ Share או Copy link ולשתף עם הצוות.
