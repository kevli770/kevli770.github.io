## מה זה Omni ולמה זה מטורף

Omni הוא מודל הווידאו החדש של גוגל (Gemini Omni Flash). במקום לייצר סרטון מאפס, הוא מקבל סרטון אמיתי שלכם ומשנה בתוכו את המציאות: מלביש דמות, הופך אובייקט, מחליף סצנה, תוך שמירה על התנועה, התאורה והזווית המקוריות.

**החידוש: זה video-to-video אמיתי. הוא לא ממציא סרטון חדש, אלא לוקח את שלכם ומשנה רק את מה שביקשתם.**

אנחנו ניגשים אליו דרך Higgsfield, פלטפורמה שחושפת את המודל (וגם Veo, Kling, Sora ועוד) בתור שרת MCP שאפשר לחבר ישירות ל-Claude Code, ולהפעיל הכל בשיחה רגילה.

## מה צריך כדי להתחיל

- חשבון Higgsfield (יש שכבה חינמית של 150 קרדיטים בחודש)
- Claude Code מותקן על המחשב
- סרטון קצר להתחיל איתו (אצלנו: סרטון של כלב, 12 שניות)

## שלב 1: לחבר את Higgsfield ל-Claude Code

החיבור נעשה בפקודה אחת בטרמינל. היא מוסיפה את שרת ה-MCP של Higgsfield ל-Claude Code:

```bash
claude mcp add --transport http --scope user higgsfield https://mcp.higgsfield.ai/mcp
```

בפעם הראשונה ש-Claude ישתמש בכלי, ייפתח דפדפן לאישור התחברות (OAuth) לחשבון Higgsfield שלכם. מתחברים, חוזרים לטרמינל, וזהו. אין צורך במפתח API.

כדי לוודא שהחיבור עלה:

```bash
claude mcp list
```

## שלב 2: התהליך, מה בעצם עשינו

אחרי שהחיבור מוכן, כל התהליך קורה בשיחה רגילה מול Claude Code. ככה זה עבד אצלנו:

### א. מעלים את הסרטון

מבקשים מ-Claude להעלות את קטע המקור ל-Higgsfield. הוא חותך את הקטע הרלוונטי, מעלה אותו ומאשר אותו, הכל אוטומטית.

### ב. נותנים פרומפט של השינוי

מתארים ל-Claude מה לשנות. לדוגמה: קח את הסרטון של הכלב, וברגע שאני מקיש באצבעות הפוך אותו לכלב עם חליפת איירון מן.

### ג. Claude מפעיל את מודל Omni

Claude קורא למודל gemini\_omni עם הפרומפט וקטע המקור. היצירה לוקחת בערך דקה, ומחזירה סרטון 720p באורך 4 עד 10 שניות.

### ד. מרכיבים את הסרטון הסופי

מורידים את התוצאה ומחברים: הצילום המקורי עד רגע ההקשה, ואז חיתוך חד לקליפ שנוצר. אצלנו הוספנו גם פלאש לבן קצר ואפקט קול, כדי שהמעבר ייראה כמו קסם.

## דוגמה מעשית: מכלב לאיירון מן

הנה בדיוק מה שיצרנו. משמאל הפריים המקורי, מימין הפריים אחרי ש-Omni הלביש את הכלב בחליפה: אותו חדר, אותה תאורה, אותה תנוחה, רק החליפה נוספה.

| לפני | אחרי |
|---|---|
|   |   |

הפרומפט שנתנו למודל (באנגלית, ככה הוא עובד הכי טוב):

```
Dress the dog in a red and gold Iron Man armored suit with a
glowing arc reactor. Keep the dog's own head, the same room,
floor, lighting and camera angle. photorealistic, cinematic.
```

## הסוד לפרומפט טוב: 3 חלקים

המודל משנה בדיוק את מה שאתם מתארים, ועלול לשנות גם דברים שלא ביקשתם. לכן פרומפט טוב תמיד מכיל 3 חלקים:

| חלק | מה זה | דוגמה |
|---|---|---|
| `ACTION` | מה משתנה | הפוך את X ל-Y באותו מקום |
| `LOCK` | מה חייב להישאר | אותו חדר, אותה זווית, אותה תאורה, אותה דמות |
| `REALISM` | לסגור עם | `realistic, cinematic, photorealistic` |

מה שלא תנעלו (LOCK), המודל עלול לשנות. ככל שתפרטו יותר מה נשאר, התוצאה יציבה יותר.

## טיפים מהשטח

- קטע מקור קצר עובד הכי טוב, 4 עד 10 שניות, וזה גם מה שהמודל מחזיר
- אם רוצים שינוי שמופעל ברגע מסוים (כמו הקשה באצבעות), צלמו את התנועה. זה נותן טריגר ויזואלי לקסם
- לפעמים המודל מחזיר בטעות שגיאת nsfw על קטע נקי לגמרי, פשוט מנסים שוב או משנים מעט את הניסוח
- אם התוצאה משנה צבע של חולצה או עצם שלא רציתם, הוסיפו נעילה מפורשת בפרומפט
- תמיד סוגרים את הפרומפט עם photorealistic, cinematic כדי שהתוצאה לא תיראה מצוירת
- הסאונד עושה חצי מהעבודה, פלאש קצר ואפקט קול על רגע השינוי מוכרים את הקסם

## מגבלות שכדאי להכיר

- הרזולוציה כרגע 720p בלבד
- אורך הקליפ 4 עד 10 שניות לכל יצירה
- כל יצירה עולה בערך 24 קרדיטים
- שינויים גדולים מאוד בסצנה יוצאים יציבים יותר בלכידה רחבה (wide shot)
