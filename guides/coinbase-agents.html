מה זה Coinbase for Agents

עד עכשיו סוכן AI היה יכול להסביר לכם מה קורה בשוק. הוא לא היה יכול ללחוץ על כפתור הקנייה. Coinbase for Agents משנה בדיוק את זה: Coinbase פתחה שרת MCP רשמי משלה שמחבר את חשבון המסחר האמיתי שלכם ישירות לסוכן, עם הרשאת כתיבה, כלומר ביצוע פקודות, לא רק צפייה.

ב-10 בספטמבר 2026 האינטגרציה עלתה לאוויר גם ב-גרוק. היא נבנתה במשותף על ידי xAI ו-Coinbase, ולכן בניגוד לחיבורי צד שלישי הישנים שהיו לקריאה בלבד, לגרוק יש כאן גישת כתיבה מלאה.

השרת עצמו נמצא בכתובת אחת, והחיבור נעשה דרך OAuth:

https://agents.coinbase.com/mcp

איפה זה עובד כבר היום

הגישה לשרת המרוחק פתוחה רק לרשימת סוכנים מאושרת:

  • ChatGPT
  • Grok
  • Perplexity Computer
  • Claude
  • Claude Code

Codex מופיע בתיעוד כ-בקרוב. לכל סוכן אחר יש מסלול CLI, שמופיע בהמשך המדריך.

ההרשאות שאתם מאשרים: מילה במילה

הצ’קליסט לפני שאתם מחברים כסף אמיתי

אל תחברו את החשבון הראשי. עברו על שבעת הסעיפים האלה לפי הסדר:

  1. פתחו תיק Advanced נפרד. אל תשתמשו בתיק שבו יושב כל הכסף שלכם. Coinbase עצמה ממליצה על זה בתיעוד.
  2. הפקידו בו רק סכום שאתם מוכנים להפסיד. זו התקרה האמיתית שלכם, כל שאר המגבלות הן רק שכבות נוספות.
  3. הורידו את הסימון מ-Allow access to all portfolio and wallet accounts ובחרו רק את התיק המבודד.
  4. אם אתם עובדים עם מפתח API, הדליקו Trade, השאירו Transfer כבוי. בלי Transfer הסוכן לא יכול להזיז כסף בין התיקים שלכם בכלל.
  5. בקשו תצוגה מקדימה לפני כל פקודה. נסחו את הבקשה כך שהסוכן יראה לכם את הפקודה ויחכה לאישור, במקום לשלוח אותה מיד.
  6. התחילו מסכום זעיר. פקודה ראשונה של דולר או שניים, רק כדי לוודא שהוא מבין נכון את הנכס ואת הכיוון.
  7. שמרו את דף הניתוק פתוח. הכתובת לניתוק מיידי נמצאת בסוף המדריך. תדעו איפה היא לפני שאתם צריכים אותה.

ההמלצה של Coinbase עצמה על תיק מבודד

איך מחברים בגרוק: שלב אחר שלב

  1. נכנסים ל-grok.com ופותחים את התפריט התחתון שמאלי, Plugins.
  2. עוברים ללשונית Connectors ומקלידים בחיפוש coinbase.
  3. תחת הקטגוריה Finance מופיע Coinbase, agents.coinbase.com. לוחצים Add.
  4. נפתח כרטיס עם כתובת השרת ואזהרה שקונקטורים של צד שלישי לא נבנו ולא מתוחזקים על ידי xAI. לוחצים Connect.
  5. נפתח מסך ההסכמה של Coinbase. כאן עוצרים וקוראים: ומורידים את הסימון מהצ’ק-בוקס של כל התיקים.
  6. לוחצים Continue, וחוזרים לשיחה עם הקונקטור מחובר.

מרגע זה אפשר פשוט לכתוב בשיחה: “מה היתרה שלי?” וגרוק מושך את הנתונים מהחשבון האמיתי.

הדרך עם השליטה המלאה: מפתח API

החיבור המהיר דרך OAuth נוח, אבל מפתח API נותן לכם שליטה גרעינית על מה הסוכן יכול לעשות. כך יוצרים אותו:

  1. נכנסים ל-portal.cdp.coinbase.com/api-keys/secret ולוחצים Create API Key.
  2. נותנים שם שמסגיר את הייעוד, למשל my-trading-agent.
  3. תחת Advanced Settings > Coinbase App & Advanced Trade בוחרים ב-Accounts את התיק המבודד שפתחתם.
  4. מגדירים את שני המתגים לפי הטבלה למטה.
  5. אם לא הגדרתם רשימת כתובות IP מורשות, מסמנים Opt out of IP allowlisting.
  6. לוחצים Create & Download ושומרים את קובץ ה-JSON. הסוד מוצג רק פעם אחת, ברגע היצירה.
מתגמה הוא מאפשרמה הוא לא מאפשר
Tradeלהציב פקודות קנייה ומכירה ולנהל אותןבלי המתג הזה הסוכן יכול רק להסתכל
Transferלהעביר כספים בין התיקים שלכם בלבדלא מאפשר משיכה לכתובת חיצונית. בכלל

ההמלצה שלי: Trade דלוק, Transfer כבוי. אם הסוכן לא אמור להזיז כסף בין תיקים, אל תיתנו לו את היכולת מלכתחילה.

התקנה ידנית דרך ה-CLI

לסוכן שלא נמצא ברשימה המאושרת, או לעבודה מהטרמינל. דורש Node.js גרסה 22 ומעלה:

npm install -g @coinbase/coinbase-cli
coinbase --version

מחברים את המפתח ומוודאים שהוא עובד:

coinbase env live --key-file <path-to-key.json>
coinbase env
coinbase balance

על לינוקס צריך גם תמיכה ב-keyring:

which secret-tool || sudo apt install -y libsecret-tools

איך מנתקים: שמרו את הקישור הזה

ניתוק מיידי של כל אפליקציה מחוברת נעשה מתוך חשבון Coinbase, במסך Security > Connections:

accounts.coinbase.com/security/connections

אם עבדתם עם מפתח API, מחיקת המפתח בפורטל מנתקת גם היא את הגישה מיידית.

מה Coinbase עצמה כותבת על הסיכון

זו לא אזהרה שלי. זה הדיסקליימר הרשמי בתחתית התיעוד שלהם:

“AI agents can make errors, misinterpret instructions, or produce inaccurate output. Coinbase does not guarantee the accuracy of any action taken by an AI agent using this product. You are solely responsible for reviewing and authorizing any trades, transfers, or account changes made through agentic workflows.”

בתרגום חופשי: הסוכן עלול לטעות, לפרש לא נכון ולהפסיד לכם כסף, והאחריות המלאה על כל עסקה היא שלכם.

יש עוד אזהרה שקל לפספס: במצבי חשיבה מורחבת בפלטפורמות מסוימות הסוכן לפעמים מנסח פקודה אבל לא באמת שולח אותה. אל תניחו שפקודה בוצעה רק כי הסוכן אמר שהוא ביצע אותה, תמיד תאמתו מול היתרה או מול היסטוריית הפקודות.

טיפים

  • נסחו את הבקשה במשפט אחד שלם: סוג הפקודה, הסכום, הנכס והתיק. לדוגמה, קנה ב-1 USDC אתריום בתיק הסוכן. בקשה חלקית מכריחה את המודל לנחש.
  • מודלים חלשים יותר מבלבלים בין נכסים דומים, למשל ETH-USD במקום ETH-USDC. בקשו אישור לפני שליחה.
  • Claude מציג תצוגה מקדימה ומבקש אישור בצ’אט, ChatGPT יוצר את הפקודה בתור אחד. שווה לדעת מי מהם אתם מריצים.
  • למשימות מרובות שלבים או מנוסחות במעורפל השתמשו במודל עם חשיבה גבוהה, הוא מתקן בקשות חסרות טוב יותר.
  • אל תשאירו את החיבור פעיל אחרי שסיימתם להתנסות. ניתוק לוקח שלוש שניות, והוא הפעולה הכי משתלמת בכל המדריך הזה.
  • אם אתם רוצים אוטומציה שרצה לבד, תכננו אותה על התיק המבודד בלבד, ועם סכומים שלא ישנו לכם אם ייעלמו.

מגבלות

  • תיקי סוכן מבודדים תומכים בספוט קריפטו בלבד. נגזרים אמריקאיים זמינים רק בתיק ברירת המחדל, מה שאומר שמסחר בחוזים עתידיים דורש לפתוח את ההרשאה לתיק הראשי.
  • הרשאת Transfer מאפשרת העברות בין החשבונות שלכם בלבד. משיכה לכתובת חיצונית לא נכללת, וזה טוב.
  • השרת המרוחק פתוח רק לרשימת סוכנים מאושרת. לכל השאר יש רק מסלול CLI.
  • הדגל —watch עובד רק על שלוש פקודות, ורק עם CLI מקומי ומפתח CDP.

לינקים

  • התיעוד הרשמי: docs.cdp.coinbase.com/coinbase-for-agents/overview
  • יצירת מפתח API: portal.cdp.coinbase.com/api-keys/secret
  • ניתוק חיבורים: accounts.coinbase.com/security/connections
  • גרוק: grok.com
  • המדריך הזה הוא מידע טכני בלבד ולא ייעוץ השקעות. מסחר בנכסים פיננסיים כרוך בסיכון להפסד מלא של הכסף.
