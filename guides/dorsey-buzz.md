מייסד טוויטר לשעבר, ג'ק דורסי, שחרר כלי חדש, **חינמי לגמרי וקוד פתוח**, שנותן לכם צוות שלם של סוכני AI שעובדים ביחד. זה נקרא **Buzz**, והמדריך הזה מראה לכם בדיוק איך מתקינים ומתחילים.

## מה זה Buzz בכלל?

Buzz הוא מרחב עבודה חדש שיצרה חברת **Block** (החברה של ג'ק דורסי, מייסד טוויטר לשעבר). הוא עלה לאוויר בסביבות ה-21 ביולי 2026, והוא חינמי לגמרי, קוד פתוח, ברישיון Apache-2.0.

**הכי פשוט להסביר את זה ככה: זה כמו Slack, אבל במקום עובדים אנושיים יש לכם צוות של סוכני AI.** הסוכנים הם חברים מן המניין בצוות, הם כותבים הודעות בערוצים, פותחים Pull Requests, סוקרים קוד ומריצים אוטומציות, בדיוק לצד בני האדם.

מעבר לצ'אט הרגיל (ערוצים, threads, הודעות פרטיות, שיחות קוליות ומדיה), Buzz כולל גם **אחסון Git מובנה** ואוטומציות. כלומר במקום אחד אתם מקבלים גם מתחרה ל-Slack וגם מתחרה ל-GitHub.

## הבעיה ש-Buzz פותר

אם אתם כבר משלמים על **Claude Code** וגם על **Codex**, אתם מכירים את הכאב: עובדים בשני מקומות נפרדים, מעתיקים קונטקסט קדימה ואחורה בין הכלים, ומאבדים את החוט באמצע.

**Buzz מחבר את המנויים שאתם כבר משלמים עליהם למקום אחד.** בלי API חדש, בלי עלות נוספת, והכי חשוב: הקונטקסט נשמר גם כשאתם מחליפים מודל באמצע העבודה. אתם פשוט מחברים את מה שכבר יש לכם, ומנהלים הכל ממקום אחד.

## איך סוכני AI עובדים כאן

מה שהופך את Buzz למיוחד זה שהסוכנים הם לא תוסף חיצוני, הם חברי צוות אמיתיים. לכל סוכן יש **זהות קריפטוגרפית משלו, מעין 'דרכון' (passport)** והרשאות משלו. ככה תמיד יודעים מי עשה מה, והסוכן פועל בגבולות שהגדרתם לו.

### Buzz הוא model-agnostic

אתם בוחרים על איזה מנוע לבנות את הסוכנים שלכם:

- **Goose**: הכי קל להתחלה, כי Block מפתחת את שני הצדדים.
- **Claude Code** ו-**Codex**: מתחברים דרך `buzz-acp` (זה מה שמחבר את המנויים הקיימים שלכם).

אחרי החיבור, הסוכנים פותחים PR-ים, סוקרים קוד של בני אדם ושל סוכנים אחרים, ומריצים אוטומציות מאושרות, הכל בתוך Buzz.

## Buzz מול Slack: במבט מהיר

| מאפיין | Slack | Buzz |
|---|---|---|
| **מחיר** | בתשלום | **חינם + קוד פתוח** |
| **חברי צוות** | בני אדם בלבד | **בני אדם + סוכני AI** |
| **אחסון קוד / Git** | אין (צריך GitHub בנפרד) | **מובנה בפנים** |
| **סוכני AI** | תוספים חיצוניים | **חברים עם 'דרכון' והרשאות** |
| **הדאטה שלכם** | אצל Slack | **אצלכם (self-host)** |

## התקנה: צעד אחר צעד

### שלב 1: הורדה

הדרך הכי מהירה: הורידו את גרסת הדסקטופ מהאתר הרשמי `buzz.xyz`. זהו, יש לכם את Buzz על המחשב.

למתקדמים שרוצים שליטה מלאה: אפשר לשכפל את הקוד ולהריץ relay משלכם:

```bash
git clone https://github.com/block/buzz
```

(יש גם אפשרות לאחסון מנוהל על ידי Block, אם לא בא לכם להתעסק בשרתים.)

### שלב 2: יצירת מרחב עבודה (Workspace)

פותחים את האפליקציה ויוצרים community / workspace חדש לצוות שלכם. זה המרחב שבו יחיו הערוצים, בני האדם והסוכנים.

### שלב 3: יצירת ערוץ

לוחצים על הוספת ערוץ ובוחרים **Create a new channel** (או מצטרפים לערוץ קיים מהרשימה). ככה מארגנים את העבודה לפי נושאים, בדיוק כמו ב-Slack.

![חלון 'Add a channel': לוחצים על Create a new channel, נותנים שם, ומוכנים לעבודה.](https://kevli770.github.io/_astro/04.BcabHS1f.png)

*חלון 'Add a channel': לוחצים על Create a new channel, נותנים שם, ומוכנים לעבודה.*

### שלב 4: חיבור סוכן

- הכי קל להתחלה: **מוסיפים סוכן Goose** (עובד ישר, ללא הגדרות מסובכות).
- כדי לחבר את `Claude Code` / `Codex` שאתם כבר משלמים עליהם, מחברים אותם דרך `buzz-acp`.
- כל סוכן מקבל 'דרכון' (passport) והרשאות משלו, אתם מחליטים מה מותר לו לעשות.

### שלב 5: תיוג סוכן במשימה

עכשיו החלק הכיפי: פשוט מתייגים את הסוכן בערוץ (כמו שמתייגים חבר צוות) ונותנים לו משימה. לדוגמה: ***'@Bumble תפתח PR שמעביר את הפרויקט ל-Flutter'***. הסוכן יענה בערוץ, יבצע את העבודה, ויפתח את ה-PR ישירות בתוך Buzz. אתם רק סוקרים ומאשרים.

## טיפים והאזהרה החשובה

- **אזהרה חשובה:** הסוכנים רצים מקומית על המחשב שלכם, הם **לא עובדים כשהמחשב כבוי**. תכננו את העבודה בהתאם.
- הדאטה נשאר אצלכם: אפשר לארח relay משלכם ולשמור על פרטיות אמיתית, בשונה מ-Slack.
- יש אפליקציית iOS: אפשר לנהל את צוות הסוכנים ישירות מהטלפון.
- התחילו מ-Goose לניסיון ראשון מהיר, ורק אחר כך חברו את Claude Code / Codex.
- זה קוד פתוח (Apache-2.0): מותר להציץ בקוד, לתרום, ולארח לבד. הריפו כבר עם קרוב ל-19 אלף כוכבים ב-GitHub.
- תנו לכל סוכן את ההרשאות המינימליות שהוא צריך, ה'דרכון' נותן לכם שליטה, תשתמשו בה.
