## מה זה Ox Alpha

ב-20 באוגוסט 2026 הופיע ב-OpenRouter מודל בשם **Ox Alpha** תחת המזהה stealth/ox-alpha. זה מודל reasoning שמיועד לקוד, לעבודה אג'נטית ארוכה ולעומסי production, והוא נמצא כרגע בחלון תצוגה מקדימה חינמי.

מה שהופך אותו למעניין זה לא רק המפרט אלא מי שעומד מאחוריו: **אף אחד לא יודע.** זה מודל stealth, הספק שמפעיל אותו בחר להישאר אנונימי לאורך כל התצוגה המקדימה. OpenRouter רק מנתבים אליו בקשות; הם לא הבעלים, לא המפתחים ולא הספק.

זו הפעם החמישית בערך בחצי השנה האחרונה שמודל אנונימי כזה צץ שם. הקודמים התגלו בדיעבד: חלקם כמעבדות סיניות, למשל MiMo של שיאומי. לרוב השם נחשף בדיוק כשחלון החינם נסגר.

## הדבר שחשוב להבין לפני שמריצים משהו

בדף המודל ב-OpenRouter יש באנר אזהרה שקל לפספס. זה מה שכתוב בו:

```
This stealth model is developed and operated by a third-party model
provider. Prompts and completions for this model are retained by the
provider and are not used for training.
```

תרגום לעברית פשוטה: שתי אמירות נפרדות, ואסור לבלבל ביניהן:

- הפרומפטים והתשובות שלכם לא משמשים לאימון המודל. זה טוב.
- אבל הם כן נשמרים אצל המפעיל, אותו מפעיל שאתם לא יודעים את שמו, לא יודעים איפה השרתים שלו, ולא יודעים כמה זמן הוא שומר.

**במילים אחרות: טוקנים בחינם יכולים להיות בעיית אבטחה.**

זה לא אומר לא להשתמש. זה אומר להיות מודעים למה שמזינים פנימה, ולכן החלק הכי חשוב במדריך הזה הוא הטבלה שבסוף.

## הדרך הבטוחה יותר: OpenCode Zen

OpenCode Zen הוא שער (gateway) של צוות OpenCode עם רשימה מצומצמת של מודלים שהם בדקו ובנצ'מרקו ספציפית לסוכני קוד. הוא מגיש את אותו Ox Alpha, אבל תחת מדיניות נתונים אחרת לגמרי.

מהתיעוד הרשמי של OpenCode:

```
Ox Alpha Free is a stealth model free on OpenCode for a limited time.
Its provider follows a zero-retention policy and does not use your
data for model training.
```

**כלומר דרך Zen: אין שמירת נתונים בכלל**, וגם לא אימון. זו הסיבה שעדיף להיכנס לזה דרך Zen ולא דרך OpenRouter.

|   | OpenRouter | OpenCode Zen |
|---|---|---|
| **אימון על הנתונים שלכם** | **לא** | **לא** |
| **שמירת פרומפטים ותשובות** | **כן: אצל המפעיל האנונימי** | **לא: zero retention** |
| **מחיר בזמן החלון** | חינם | חינם |
| **Model ID** | `stealth/ox-alpha` | `x-preview-f-free` |

## איך מתקינים: שלב אחרי שלב

### שלב 1: התקנת OpenCode

פקודה אחת בטרמינל, אם יש לכם Node מותקן:

```bash
npm i -g opencode-ai
```

יש גם דרכים אחרות: curl, bun, brew או paru:

```bash
curl -fsSL https://opencode.ai/install | bash
```

### שלב 2: להריץ את OpenCode בתיקיית הפרויקט

```
opencode
```

זה פותח את ה-TUI (הממשק בטרמינל) על התיקייה הנוכחית.

### שלב 3: לחבר את OpenCode Zen

נרשמים ל-OpenCode Zen, מוסיפים פרטי חיוב ומעתיקים את מפתח ה-API. אחר כך, בתוך ה-TUI:

```
/connect
```

בוחרים **OpenCode Zen** מהרשימה ומדביקים את המפתח.

שימו לב: המודל עצמו חינמי, אבל Zen מבקש כרטיס כדי לפתוח חשבון (מודלים אחרים שם עולים כסף לפי שימוש). אפשר להגדיר תקרת שימוש חודשית ולכבות טעינה אוטומטית של יתרה.

### שלב 4: לבחור את המודל

```
/models
```

ברשימה בוחרים **Ox Alpha Free**. זהו: אתם עובדים.

## שימוש ישיר דרך API

אם אתם לא רוצים את ה-TUI ורק צריכים את המודל בקוד, Zen חושף endpoint תואם OpenAI:

```
Model ID:  x-preview-f-free
Endpoint:  https://opencode.ai/zen/v1/chat/completions
SDK:       @ai-sdk/openai-compatible
```

דרך OpenRouter, לשם השוואה, המזהה הוא stealth/ox-alpha מול ה-API הרגיל שלהם, אבל אז חלה עליכם מדיניות השמירה של המפעיל האנונימי.

## מה מותר ומה אסור להזרים למודל אנונימי

**זה הלב של המדריך. הכלל הפשוט: תשמרו את זה לפרויקטים צדדיים, לא לכאלה שבהם אבטחת מידע חשובה לכם.**

| מותר: קדימה | אסור: עצרו |
|---|---|
| פרויקטי צד, hobby, ניסויים | קוד קנייני של הלקוח או של החברה |
| קוד open-source שכבר פומבי בגיטהאב | קבצי env, מפתחות API, טוקנים וסיסמאות |
| תרגילים, לימוד ו-POC-ים | מידע אישי מזהה של לקוחות (PII) |
| בדיקת היכולות של המודל עצמו | dumps של בסיס נתונים או לוגים מפרודקשן |
| קוד גנרי: אלגוריתמים, utils, boilerplate | חוזים, מסמכים משפטיים ונתונים פיננסיים |
| תיעוד ציבורי וקבצי README | מידע רפואי או כל דבר תחת רגולציה |
| סקיצות ארכיטקטורה בלי שמות אמיתיים | כל דבר שחתום תחת NDA |

**שימו לב במיוחד לסוכני קוד:** סוכן שרץ בתיקיית הפרויקט קורא קבצים בעצמו. גם אם אתם לא מדביקים את קובץ ה-env ידנית, הוא עלול לקרוא אותו ולשלוח אותו למודל. הריצו את זה בתיקייה נקייה, או הוסיפו חוקי הרשאות שחוסמים קבצי סודות.

## טיפים

- החלון החינמי מוגבל בזמן: הוא נפתח ב-20 באוגוסט ולפי הפרסומים אמור להיסגר סביב ה-27 בחודש. בדרך כלל אז גם השם האמיתי של המודל מתגלה.
- אם אתם רוצים לנסות אותו על משהו רגיש, אל תנסו. תחכו שהמודל ייצא רשמית ותקראו את מדיניות הפרטיות של מי שמאחוריו.
- פתחו תיקיית sandbox נפרדת לניסויים עם מודלים אנונימיים, ותנו לסוכן גישה רק אליה.
- הוסיפו קבצי env וסודות ל-gitignore וגם לחוקי ההרשאות של OpenCode.
- הגדירו ב-Zen תקרת שימוש חודשית וכבו טעינה אוטומטית של יתרה, כדי שלא תופתעו כשהחינם ייגמר.
- אפשר להשתמש ב-Zen עם כל סוכן קוד, לא רק עם OpenCode, ה-endpoint תואם OpenAI.
- בדקו את המודל על משימה אחת ארוכה, זה בדיוק מה שחלון של מיליון טוקנים אמור לתת.

## מגבלות

- ספק יחיד: אין ניתוב חלופי. אם הספק נופל, המודל לא זמין.
- המהירות שנמדדה בתצוגה המקדימה היא סביב 18 טוקנים לשנייה, עם השהיה של כמעט 7 שניות לתשובה. זה לא המודל הכי מהיר שיש.
- מודל stealth יכול להיעלם בלי התראה, אל תבנו עליו משהו בפרודקשן.
- רשימת המודלים החינמיים של Zen משתנה, מה שחינם היום עשוי לא להיות חינם מחר.
