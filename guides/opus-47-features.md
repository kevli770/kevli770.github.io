## 5 דברים שצריך לדעת על Opus 4.7

Anthropic שחררו את Claude Opus 4.7 ב-15 באפריל 2026. אותו מחיר, אותם בנצ'מרקים. כולם מדברים על זה אבל הנה 5 דברים שבאמת משנים את איך עובדים עם Claude Code.

| # | פיצ'ר | במשפט אחד |
|---|---|---|
| **1** | **Auto Mode** | Claude מחליט לבד מה בטוח ומה לא |
| **2** | `/ultrareview` | 4 סוכנים בודקים את הקוד במקביל |
| **3** | `/fewer-permission-prompts` | מפסיק לשאול על דברים שכבר אישרתם |
| **4** | `/recap` | תקציר מהיר של מה קרה בסשן |
| **5** | `/effort` | לקבוע כמה קשה Claude חושב |

## 1. Auto Mode: בלי הפסקות

עד עכשיו Claude שאל אישור על כל פעולה. עכשיו הוא מבין לבד מה בטוח ומה לא. פעולה בטוחה? פשוט עושה. פעולה מסוכנת? רק אז שואל.

### איך זה עובד טכנית

מערכת הגנה דו-שכבתית:

- שכבה 1: סורק קלט בצד השרת מזהה תוכן זדוני בפלטים של הכלים
- שכבה 2: מסווג שמשתמש ב-Sonnet 4.6 להעריך כל פעולה לפני ביצוע

### מה נחסם

- force push, מחיקת קבצים גורפת
- שליחת מידע פנימי החוצה
- הרצת קוד חיצוני בלי אישור
- שינוי הרשאות והגדרות אבטחה

### מה מותר

- קריאת קבצים, חיפוש בקוד
- עריכת קבצים בתוך הפרויקט
- הרצת טסטים, התקנת חבילות מוצהרות

### איך מפעילים

בבורר המודלים ב-Claude Code, לבחור Auto. או דרך ה-CLI:

```bash
claude config set autoMode true
```

*זמין ל-Pro, Max, Team, Enterprise. דורש גרסה 2.1.83+.*

## 2. /ultrareview: 4 מומחים בודקים את הקוד

כתבתם קוד ולפני שאתם מפרסמים, Claude שולח את זה ל-4 סוכנים שבודקים במקביל:

| סוכן | מה בודק |
|---|---|
| **אבטחה** | פרצות אבטחה, הזרקות, XSS, SQL injection, secrets בקוד |
| **לוגיקה** | באגים לוגיים, edge cases, מצבים שלא טיפלו בהם |
| **ביצועים** | צווארי צרכן, זיכרון, קריאות מיותרות, אופטימיזציה |
| **עיצוב/תחזוקה** | קריאות קוד, מבנה, שמות, דפוסי קוד אחידים |

### איך משתמשים

```
/ultrareview
```

*פרו ומקס מקבלים 3 ultrareviews חינם.*

ההבדל מ-/review רגיל: /review הוא סוכן יחיד שעובר על הקוד. /ultrareview הם 4 סוכנים שעובדים במקביל וכל אחד מתמחה בתחום אחר. כמו 4 מומחים שבודקים את העבודה שלכם בלחיצת כפתור.

## 3. /fewer-permission-prompts: פחות הפרעות

Claude עובר על ההיסטוריה שלכם, רואה אילו פקודות אישרתם בעבר, ומוסיף אותן אוטומטית לרשימת המותר. כך הוא מפסיק להפריע על דברים שכבר אישרתם 10 פעמים.

### איך משתמשים

```
/fewer-permission-prompts
```

הפקודה סורקת את ההיסטוריה ומציעה רשימת פקודות בטוחות להוסיף ל-

```
.claude/settings.json
```

אתם מאשרים כל הצעה לפני שהיא נשמרת.

## 4. /recap: איפה הפסקנו

באמצע עבודה ארוכה ולא זוכרים מה Claude עשה? /recap נותן תקציר מהיר של מה קרה ומה הצעד הבא.

### איך משתמשים

```
/recap
```

### רקפ אוטומטי

כשהטרמינל לא בפוקוס לפחות 3 דקות, Claude מכין רקפ ברקע. כשחוזרים: התקציר מוכן.

- מופיע רק אחרי 3+ turns בסשן
- לא מופיע פעמיים ברצף
- לכיבוי דרך /config: להפעיל/לכבות Session recap

## 5. /effort: רמת חשיבה

עכשיו אפשר להגדיר כמה קשה Claude חושב. למשימות פשוטות: נמוך ומהיר. למשימות מורכבות: איטי יותר אבל הרבה יותר מדויק.

| רמה | מתי להשתמש | הערות |
|---|---|---|
| `low` | שאלות פשוטות, בדיקות מהירות | מהיר, חוסך טוקנים |
| `high` | רוב המשימות היומיומיות | איזון טוב בין מהירות לדיוק |
| `xhigh` | ברירת מחדל ב-Opus 4.7: בין high ל-max | הדיפולט החדש ב-Claude Code |
| `max` | המשימות הכי קשות | איטי, חל רק על הסשן הנוכחי |

### איך משתמשים

```
/effort xhigh
/effort low
claude --effort max
```

*effort נשמר בין סשנים, חוץ מ-max שחל רק על הסשן הנוכחי.*
