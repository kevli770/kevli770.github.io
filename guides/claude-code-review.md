> Code Review היא יכולת רשמית של Anthropic בתוך Claude Code שסורקת שינויים בקוד ומאתרת באגים לוגיים, פרצות אבטחה ורגרסיות.

מאת קווין ליאקס. פורסם 2026-07-19. נושא: Claude ו-Claude Code.
העמוד המלא: https://kevli770.github.io/guides/claude-code-review

## מה זה Code Review של Claude Code

כולם למדו לייצר קוד עם AI, מהר ובכמויות. אבל דווקא בגלל זה נולדה בעיה חדשה: מי בודק את כל הקוד הזה? כתיבת הקוד נהייתה החלק הקל. הבדיקה שלו היא האתגר האמיתי, וזו שקובעת אם המוצר שלכם עובד או קורס.

Code Review היא יכולת רשמית של Anthropic בתוך Claude Code שסורקת שינויים בקוד ומאתרת באגים לוגיים, פרצות אבטחה ורגרסיות. במקום מפתח אחד שקורא דיף, צי סוכנים מתמחים בוחן את השינוי בהקשר של כל בסיס הקוד שלכם.

**החשוב מכל: זו המערכת ש-Anthropic עצמה מריצה כמעט על כל PR פנימי.**

## הנתונים: למה זה משנה

כל הנתונים הבאים מגיעים ישירות מ-Anthropic (הבלוג הרשמי של code review):

- תפוקת הקוד לכל מהנדס ב-Anthropic גדלה ב-200% בשנה האחרונה. ה-review הפך לצוואר בקבוק.
- לפני Code Review, 16% מה-PR קיבלו הערות ביקורת מהותיות. היום 54%.
- על PR גדולים (מעל 1000 שורות), 84% מקבלים ממצאים, בממוצע 7.5 בעיות לכל PR.
- המהנדסים מסכימים עם הממצאים: פחות מ-1% מסומנים כשגויים.
- בדיקה ממוצעת אורכת בערך 20 דקות, ומקבלת יותר סוכנים ועומק ככל שה-PR גדול יותר.

## איך משתמשים: בדיקה מקומית

הדרך הכי מהירה להתחיל: בתוך Claude Code, על ה-branch שאתם עובדים עליו, הריצו את הפקודה:

```
/code-review
```

הפקודה בודקת את הדיף של ה-branch הנוכחי מול הבסיס, ומחזירה רשימת ממצאים ממוינת לפי חומרה (Critical / Important / וכו'). זמין בכל התוכניות, גם בלי GitHub.

רוצים בדיקה אוטומטית על כל PR ב-GitHub? אפשר לחבר את השירות המנוהל שמפרסם הערות inline ישירות על שורות הקוד. אפשר גם לבקש בדיקה חוזרת מ-PR עם תגובה:

```
@claude review
```

## רמות מאמץ (Effort Levels)

השדרוג הגדול: הפקודה קיבלה רמות מאמץ. אתם בוחרים כמה עמוק לחפור. רמות נמוכות מחזירות פחות ממצאים אבל בביטחון גבוה ומהר; רמות גבוהות מרחיבות את הכיסוי (וגם עשויות לכלול ממצאים פחות ודאיים).

| רמה | מתי להשתמש |
|---|---|
| `low` | מהיר וזול. פחות ממצאים אבל בביטחון גבוה. אפילו ברמה הזולה קלוד תופס בערך 17% יותר באגים מהמתחרים המובילים בשוק. |
| `medium` | איזון טוב לרוב ה-PR היומיומיים. עדיין מהיר, כיסוי רחב יותר מ-low. |
| `high` | כיסוי רחב. שווה ל-PR מורכבים או קריטיים. עשוי לכלול ממצאים לא ודאיים לצד הוודאיים. |
| `max` | העומק המקסימלי. הכי יסודי (וגם הכי יקר) לפני החלטות חשובות. |

## אולטרה-ריוויו (code-review ultra)

רוצים עומק מלא לפני מיזוג? זו הרמה הכי חזקה. הפקודה:

```
/code-review ultra
```

אולטרה-ריוויו מפעילה צי סוכנים בענן (לא על המחשב שלכם) שמחפשים באגים במקביל, ואז מאמתים כל ממצא באופן עצמאי כדי לסנן false positives. רק באגים שאומתו מוצגים לכם.

- רץ בענן על תשתית של Anthropic, בערך 5 עד 10 דקות.
- כל באג מאומת בנפרד לפני שהוא מוצג לכם.
- מנויי Pro ו-Max מקבלים 3 הרצות חינם; אחר כך בערך 5 עד 20 דולר להרצה, לפי גודל ה-PR.

## דוגמה מעשית: זרימת עבודה

- עבדתם על פיצ'ר, סיימתם commit על branch. הריצו /code-review ברמת medium לבדיקה מהירה.
- עברתם על הממצאים, תיקנתם את ה-Critical וה-Important, ודחפתם.
- לפני מיזוג ל-main, הריצו /code-review ultra לבדיקה עמוקה שמאמתת כל באג בענן.
- מיזגתם בראש שקט: כי כל באג עבר אימות לפני שראיתם אותו.

## טיפים

- כוונו את מה שקלוד מסמן בעזרת קובץ CLAUDE.md או REVIEW.md ב-repo.
- התחילו ב-low/medium ליומיום; שמרו high/max ל-PR מורכבים או קריטיים.
- אולטרה-ריוויו הכי משתלמת רגע לפני מיזוג ל-main, לא על כל commit קטן.
- הממצאים לא מאשרים או חוסמים PR, זו עדיין החלטה אנושית. הם רק סוגרים את הפער.
- על PR גדולים תקבלו יותר ממצאים; על שינויים זעירים לפעמים 0, זה תקין.

## מגבלות

- השירות המנוהל ל-PR הוא ב-research preview, זמין למנויי Team ו-Enterprise (לא בארגונים עם Zero Data Retention).
- בכל תוכנית אחרת עדיין אפשר להריץ /code-review מקומית על הדיף.
- בדיקה מנוהלת מחויבת לפי צריכת טוקנים, בממוצע בערך 15 עד 25 דולר, לפי גודל ה-PR.
