העמוד המלא: https://kevli770.github.io/guides/vercel-eve

## מה זה eve?

ב-17 ביוני 2026, בכנס Ship של Vercel בלונדון, חברת Vercel (אותם אנשים שמאחורי Next.js) שחררה בקוד פתוח Framework חדש בשם **eve**, מסגרת לבניית סוכני AI. הם קוראים לזה *"ה-Next.js של הסוכנים"*.

**הקוד פתוח לגמרי תחת רישיון Apache 2.0, חינם, וזמין ב-GitHub. במקום להרכיב לבד עשרות ספריות, eve נותן לכם מסגרת אחת שכבר כוללת את כל מה שצריך כדי לבנות, להריץ ולתחזק סוכן בייצור אמיתי.**

## הרעיון המרכזי: כל סוכן הוא תיקייה אחת

זה החלק היפה. ב-eve כל סוכן הוא פשוט תיקייה עם קבצים, בלי קוד מורכב. כל קובץ או תת-תיקייה מגדירים חלק אחר בסוכן: ההוראות, הסקילים, הכלים, הערוצים והתזמונים.

```
agent/
  agent.ts          # הגדרת המודל (model provider)
  instructions.md   # ההוראות והאישיות של הסוכן
  tools/            # כלים מותאמים (TypeScript)
  skills/           # ידע וסקילים (Markdown)
  subagents/        # תתי-סוכנים להאצלת משימות
  channels/         # ערוצים: Slack, Discord, Teams...
  schedules/        # תזמונים אוטומטיים (cron)
  connections/      # חיבורי API ו-MCP
```

## מה מקבלים מובנה (בלי להרכיב לבד)

eve מגיע עם שש יכולות ייצור מובנות כברירת מחדל, פלוס תשתית ערוצים ותזמון:

- ביצוע עמיד (Durable Execution): הסוכן ממשיך מאיפה שנעצר גם אחרי כשל או הפסקה
- סביבת Sandbox מבודדת: כל סוכן מריץ קוד בבידוד מלא מהאפליקציה שלכם
- אישורי אנוש (Human-in-the-loop): הסוכן עוצר ומבקש אישור לפני פעולות רגישות
- תתי-סוכנים (Subagents): האצלת משימות לסוכנים נוספים שעובדים במקביל
- מערכת Evals מובנית: בדיקת איכות אוטומטית של הסוכן לאורך זמן
- OpenTelemetry: מעקב ותצפית מלאה על כל מה שהסוכן עושה
- ריבוי ערוצים: Slack, Discord, Teams, GitHub, Linear, Telegram, Twilio

## איך מתחילים: שתי פקודות

פקודה אחת יוצרת סוכן חדש מאפס:

```bash
npx eve@latest init my-agent
```

ופקודה אחת מעלה אותו לייצור, בדיוק אותה פקודה שמעלה אתר רגיל ב-Vercel:

```
vercel deploy
```

## הקאץ' שחשוב להבין

הקוד של eve פתוח לגמרי ואפשר להריץ אותו בכל מקום. אבל שתי התכונות החזקות ביותר, ה-Sandbox המבודד והפריסה בלחיצה אחת, עובדות הכי חלק על התשתית של Vercel עצמם.

**כלומר: הקוד חינם ופתוח, אבל החוויה המלאה והקלה ביותר נשענת על הענן של Vercel. זה לא מקרי, Vercel בנו את eve על בסיס מה שהם כבר מריצים אצלם בייצור.**

## דוגמאות מהשטח: הסוכנים של Vercel עצמם

Vercel מריצים יותר מ-100 סוכנים על eve בייצור אמיתי. הנה כמה מהבולטים:

| הסוכן | מה הוא עושה |
|---|---|
| **d0: אנליסט נתונים** | עונה על יותר מ-30,000 שאלות בכל חודש דרך Slack |
| **Vertex: תמיכה** | סוגר 92% מהפניות לבדו, בלי בן אדם בלולאה |
| **Lead Agent: מכירות (SDR)** | מחזיר פי 32 מעלות התפעול השנתית שלו |
| **Athena: Sales Cockpit** | נבנה ב-6 שבועות בלבד, בלי מהנדסים |
| **V: סוכן ניתוב** | מתאם בין מאות סוכנים שרצים במקביל |

## טיפים מהשטח

- התחילו מסוכן אחד קטן וממוקד לפני שמרכיבים מערכת שלמה של סוכנים
- כתבו את ההוראות (instructions.md) בשפה פשוטה וברורה, זה הלב הפועם של הסוכן
- נצלו את ה-Sandbox כדי לתת לסוכן להריץ קוד בבטחה בלי לסכן את האפליקציה
- הוסיפו אישור אנוש לכל פעולה רגישה: מחיקה, תשלום, שליחת מייל החוצה
- חברו את הסוכן ל-Slack כדי לראות אותו עובד ולתקשר איתו בזמן אמת
- השתמשו ב-Evals אחרי כל שינוי בהוראות, כדי לדעת אם שיפרתם או הרעתם
