## ההבדל הגדול

כולם מדברים על AI אבל מעט מאוד מבינים מה ההבדל בין Claude ל-Claude Code. זה יום 1 באתגר ה-30 יום עם קלוד.

## Claude: הצ'אט

Claude זה הצ'אט. אתם כותבים לו שאלה, הוא עונה. כמו WhatsApp עם מישהו חכם. אבל יש לו בעיה אחת גדולה, הוא לא יכול לגעת בשום דבר.

- לא יכול לקרוא קבצים מהמחשב שלכם
- לא יכול להריץ קוד
- לא יכול לבדוק אתרים
- רק מקבל טקסט ומחזיר טקסט

## Claude Code: המוח עם ידיים

Claude Code זה Claude עם ידיים. אותו מוח בדיוק, אבל עם יכולת לגעת בעולם האמיתי.

- יכול לקרוא קבצים מהמחשב שלכם
- יכול לכתוב קוד
- יכול להריץ פקודות
- יכול לתקן באגים: הכל ישירות אצלכם

## איך זה עובד: מבנה

הדיאגרמה הזאת (מהקורס הרשמי של Anthropic) מראה כיצד coding assistant עובד:

![איך זה עובד: מבנה](https://kevli770.github.io/_astro/01.D4YO8xFM.png)

המשימה נכנסת לאסיסטנט. האסיסטנט משלב Language Model (Claude), סט כלים, ומבצע לולאה: אוסף הקשר, בונה תוכנית, מבצע פעולה.

## Tool Use: הקסם שמאחורי הכול

היכולת שמאפשרת הכול נקראת tool use. המערכת מוסיפה ל-Claude הוראות שאומרות לו: 'אם אתה צריך לקרוא קובץ, תבקש, ואני אקרא בשבילך.' ואז Claude מבקש, המערכת עושה, ומחזירה לו את התוצאה.

![Tool Use: הקסם שמאחורי הכול](https://kevli770.github.io/_astro/02.D0UJSqjp.png)

הוא לא באמת קורא, אבל מבחינתכם, הוא עונה כאילו קרא.

## ההבדל בפועל

| משימה | Claude | Claude Code |
|---|---|---|
| **בניית אתר** | נותן קוד להעתקה | יוצר תיקיות וקבצים ישירות |
| **תיקון באג** | מסביר מה לתקן | קורא את הקוד, מזהה, מתקן, בודק |
| **גישה לקבצים** | אין | כן |
| **הרצת פקודות** | אין | כן |
| **דרך גישה** | דפדפן / אפליקציה | טרמינל / CLI |

## דוגמה מהחיים

### רוצה לבנות אתר?

עם **Claude**: ייתן לכם קוד שתצטרכו להעתיק, להדביק ולהבין מה לעשות.

עם **Claude Code**: אומרים "תבנה לי אתר תדמית", והוא יוצר את כל התיקיות והקבצים ישירות על המחשב.
