## מה זה DeepSeek Harness

ב-13 באוגוסט 2026 DeepSeek שחררו את **DeepSeek Harness**, סביבת עבודה לסוכני קוד, בקוד פתוח, ברישיון MIT. בתוך ימים הריפו עבר 110 אלף כוכבים.

הרעיון המרכזי שלהם הוא משפט אחד: **Everything is a Plugin**. המודל, הכלים, מצב הסשן, מערכת הקבצים, ה-sandbox, לולאת הסוכן, כל אחד מהם הוא רכיב שאפשר להחליף.

## למה זה משנה לכם

תחשבו על זה כמו על רכב. הכלי שאתם עובדים איתו כל היום, הטרמינל, הסוכן, הזיכרון, ההרשאות, זה הרכב. המודל שמריץ את הקוד הוא המנוע.

ברוב הכלים היום הרכב נעול ליצרן מנוע אחד. אבל המנוע הכי טוב מתחלף כל כמה חודשים. Harness מפריד בין השניים: הרכב נשאר שלכם, והמנוע מתחלף בהגדרה אחת.

**ובפועל: אפשר להריץ אותו עם המנוי שכבר יש לכם, בלי לשלם פעמיים.**

## דרישות מקדימות

- Node.js בגרסה 22.19 ומעלה, או 24 ומעלה. גרסאות אי-זוגיות כמו 23 ייכשלו.
- חיבור אינטרנט להתקנה הראשונה.
- אם אתם הולכים על דרך א', Claude Code כבר מותקן ומחובר אצלכם.

לבדיקת הגרסה:

```bash
node -v
```

## התקנה: פקודה אחת

פותחים טרמינל בתיקיית הפרויקט שאתם רוצים לעבוד עליו, ומריצים:

```bash
npx @deepseek-ai/dsh web
```

ההתקנה הראשונה לוקחת בערך שתי דקות. בסוף הטרמינל מדפיס כתובת מקומית:

```
dsh web: http://127.0.0.1:3080
```

פותחים את הכתובת בדפדפן. בהרצה הראשונה נוצרת תיקיית הגדרות בשם `.dsh` בתיקיית הבית שלכם.

*שימו לב: התהליך משתמש בתיקייה שממנה הרצתם אותו כברירת מחדל, אז תריצו אותו מתוך הפרויקט הנכון.*

## בחירת סביבת עבודה

לפני שאפשר לכתוב הודעה ראשונה צריך לבחור workspace: לוחצים על **Choose workspace**, מוסיפים את תיקיית הפרויקט ובוחרים אותה. בלי זה תיבת הכתיבה נשארת מושבתת.

## חיבור המנוע: שלוש דרכים

זה החלק שבגללו הגעתם. יש שלוש דרכים לחבר מודל, והן לא שוות בסיכון:

| הדרך | מה עושים | למי זה מתאים |
|---|---|---|
| **א. Claude Code מותקן** | dsh מריץ את הבינארי של Claude Code שכבר יש לכם ומאציל לו עבודה | מי שכבר משלם על Claude Code, הכי נקי, בלי טוקנים שעוברים ידיים |
| **ב. מפתח API** | מוסיפים את Anthropic כספק מהקטלוג ומדביקים מפתח API | מי שיש לו מפתח API ומוכן לשלם לפי צריכה |
| **ג. התחברות עם המנוי** | תוסף צד-שלישי שעושה OAuth מול חשבון Claude Pro/Max | מתקדמים בלבד: קראו את האזהרה בהמשך |

### דרך א': להשתמש ב-Claude Code שכבר מותקן (מומלץ)

dsh מגיע עם ספקי subagent מובנים ל-Claude Code ול-Codex. הם **כבויים כברירת מחדל**. כשמפעילים אותם, dsh מאתר את הבינארי שלכם ב-PATH ומאציל לו משימות, כלומר ההתחברות והמנוי נשארים אצל הכלי הרשמי של Anthropic, ו-dsh רק מדבר איתו.

התוסף הרלוונטי:

```
@deepseek-ai/dsh-subagent-claude-code
```

מפעילים אותו בקובץ ההגדרות של הפרופיל:

```
subagent-claude-code:
  disposeGraceMs: 5000
```

בדקו קודם ש-Claude Code עצמו רץ אצלכם מהטרמינל, כי dsh מחפש אותו ב-PATH:

```bash
claude --version
```

### דרך ב': מפתח API של Anthropic

נכנסים ל-**Settings → Models**, בוחרים **Add provider**, בוחרים Anthropic מהקטלוג, מדביקים מפתח ושומרים. הקטלוג כבר יודע את הכתובת, הפרוטוקול ורשימת המודלים.

המפתח נשמר בקובץ `$DSH_HOME/.credentials.yaml`, וההגדרות עצמן מחזיקות רק הפניה אליו. המסלול נעשה זמין מיד, בלי להפעיל מחדש את השרת.

![תיעוד הספקים הרשמי של dsh](https://kevli770.github.io/_astro/02.Be5ym9Nq.png)

*תיעוד הספקים הרשמי של dsh*

### דרך ג': התחברות עם המנוי דרך תוסף

יש תוסף קהילתי בשם `dsh-subscription-auth` שמוסיף התחברות OAuth לחשבונות מנוי, Claude Pro/Max, ChatGPT, Grok ו-Kimi, במקום מפתח API.

```
dsh plugin --profile web add dsh-subscription-auth
```

אחרי ההתקנה מפעילים מחדש את dsh ועושים רענון קשה בדפדפן, ואז: **Settings → Subscription Services**, לוחצים Login ליד Claude, מאשרים בדפדפן, וחוזרים. רשימת המודלים נטענת לבד.

> **לפני שאתם הולכים על הדרך הזאת, שלוש נקודות**
>
> 1\. התוסף הוא פרויקט קהילתי חדש מאוד, עם מעט מאוד כוכבים ובלי תורמים. הוא זה שמחזיק את טוקן ההתחברות שלכם.
>
> 2\. ההרשאות שהוא מבקש כוללות גם יצירת מפתחות API בחשבון שלכם, לא רק שליחת בקשות.
>
> 3\. ההרשאה פגה בערך כל 30 יום וצריך להתחבר מחדש. בנוסף, אנתרופיק נקטה בעבר צעדים נגד שימוש במנויים דרך כלים חיצוניים, אז יש כאן סיכון לחשבון.
>
> אם אתם לא בטוחים: לכו על דרך א' או ב'. הן נותנות את אותה תוצאה בלי הסיכון.

## טיפים

- תריצו את dsh מתוך תיקיית הפרויקט, הוא לוקח אותה כברירת מחדל למערכת הקבצים.
- הוא קורא CLAUDE.md ו-AGENTS.md, אז ההוראות שכבר כתבתם לסוכן ממשיכות לעבוד.
- יש גשר ל-hooks.json הקיים שלכם מ-Claude Code ומ-Codex.
- בחירת מודל הופכת אותו לברירת מחדל לסשנים חדשים, אבל סשן שכבר שלח בקשה נשאר עם המודל שלו.
- אפשר להצביע על כל endpoint תואם OpenAI דרך custom provider, כולל שרת מקומי.
- לפרויקט יש גם MCP, אז שרתי הכלים שכבר בניתם עובדים גם כאן.
- תתחילו במשימה קטנה: למשל לבקש סיכום של הריפו, לפני שאתם נותנים לו לגעת בקוד.

## מגבלות שכדאי להכיר

- זו גרסת developer preview מסומנת 0.1, DeepSeek עצמם מזהירים משינויים שוברים.
- נקודת הכניסה המרכזית היום היא ממשק web מקומי, לא חוויית טרמינל בשלה.
- Node בגרסה אי-זוגית פשוט לא יעבוד.
- ספקים עם אימות משלהם: Bedrock, Vertex, Azure, דורשים את האישורים שלהם ולא מפתח API רגיל.
